Description détaillée

Solveur pour le mode puzzle.

Ce module fournit des fonctionnalités pour résoudre les puzzles à l'aide de divers algorithmes de parcours de graphe (DFS, BFS et A*). Une implémentation de table de hachage est également fournie pour stocker efficacement les configurations de plateau visitées par ces algorithmes. Elle est déjà programmée et vous NE DEVEZ PAS LA MODIFIER. Les seules fonctions à implémenter sont solve_puzzle() et game_implement_solver_move() à la fin de ce fichier (vous pouvez bien sûr ajouter vos propres fonctions utilitaires).

Remarques
La table de hachage ne peut stocker que des éléments encodés comme des tableaux d'entiers. Cela signifie que pour stocker des configurations de plateau, vous devez d'abord les encoder sous forme de tableaux d'entiers. De plus, la table de hachage ne stocke pas les éléments eux-mêmes, mais des indices vers un tableau de stockage externe que vous devez gérer vous-même.

Structure de table de hachage.

Utilisée pour stocker les configurations de plateau visitées par le solveur. La table de hachage ne stocke pas les configurations elles-mêmes, mais des indices vers un tableau de stockage externe passé aux fonctions de la table (nécessaire car ce tableau de stockage peut être réalloué et déplacé en mémoire).

Remarques
Chaque élément inséré doit être encodé dans le tableau externe comme une séquence d'entiers (de longueur fixe, définie à la création de la table). En particulier, les configurations de plateau doivent être encodées sous forme de tableaux d'entiers.

◆ gem_power

enum gem_power

Pouvoirs qu'une gemme peut posséder.

Il existe plusieurs types de gemmes avec pouvoirs :

  • Gemmes de gravité : lorsqu'elles sont échangées avec un autre élément, elles changent la direction de la gravité vers une direction aléatoire (différente de la direction actuelle).
  • Gemmes enflammées : lorsqu'elles sont détruites, elles détruisent également tous leurs voisins dans une zone 3x3.
  • Gemmes étoilées : lorsqu'elles sont cassées, elles effacent toute leur ligne et colonne.
Remarques
Dans l'interface graphique, ces paramètres n'affectent que la représentation visuelle de la gemme. Vous devez implémenter le comportement réel des gemmes avec pouvoirs dans la logique du jeu.
Valeurs énumérées
GEM_BASIC 

Gemme basique (sans pouvoir).

GEM_GRAVITY 

Gemme de gravité.

GEM_FLAME 

Gemme enflammée.

GEM_STAR 

Gemme étoilée.

GEM_SIZE 

Taille de l'énumération gem_power.

Appelée par l'interface pour initialiser un jeu classique avec la largeur et la hauteur spécifiées.

Alloue de la mémoire pour la structure du jeu et initialise le jeu. Les cases sont toutes remplies aléatoirement avec des types de gemmes. La génération garantit que le jeu est stable : aucune zone destructible n'existe. De plus, elle doit également garantir qu'au moins un coup peut être joué.

Attention
Comme le mode classique n'utilise pas de file de stockage, le paramètre refill_mode doit être défini à 2 (pas de file).
Renvoie
Un pointeur vers la structure de jeu initialisée.

Appelée par l'interface pour initialiser un jeu puzzle avec la largeur et la hauteur spécifiées.

Alloue de la mémoire pour la structure du jeu et initialise le jeu. Les cases sont soit vides, soit remplies aléatoirement avec des types de gemmes. La génération garantit que le jeu est stable :

  • aucune zone destructible n'existe, et,
  • il n'y a pas de case non vide au-dessus d'une case vide.

Le paramètre "balanced" indique si la génération équilibrée est activée. Lorsqu'elle est activée, le nombre de chaque type de gemme sur le plateau doit être un multiple de 3.

Le paramètre refill_mode spécifie comment la file de stockage doit être initialisée :

  • Si refill_mode est 0, la file de stockage est allouée et initialement vide. Les gemmes qui sont éliminées sont stockées dans la file de stockage et peuvent être utilisées pour remplir le plateau plus tard.
  • Si refill_mode est 1, la file de stockage est allouée et doit être remplie avec une séquence aléatoire de rochers et de bombes. La longueur de la séquence est fournie par le paramètre ini. Ce paramètre ne doit pas dépasser le nombre total de cases sur le plateau (s'il le fait, il doit être défini à width * height).
  • Si refill_mode est 2, la file de stockage n'est pas utilisée et ne doit pas être allouée.
Renvoie
Un pointeur vers la structure de jeu initialisée.
Paramètres
widthLargeur du plateau de jeu.
heightHauteur du plateau de jeu
linesMode d'élimination du jeu (lignes ou SCCs).
upgradesIndicateur indiquant si les améliorations de gemmes sont activées.
refill_modeIndicateur indiquant le mode de stockage.
iniTaille initiale du stockage (pertinent uniquement si refill_mode est défini à 1).
balancedIndicateur indiquant si la génération équilibrée est activée (le nombre de chaque type de gemme doit être un multiple de 3).
gravity_controlMode de contrôle de la gravité (0 : ne peut pas changer, 1 : rotation horaire, 2 : libre).

◆ game_next_level()

void game_next_level ( game * g)

Appelée par l'interface lorsqu'un niveau se termine en mode classique pour générer un nouveau plateau de jeu.

Cette fonction libère le plateau de jeu actuel (mais pas toute la structure du jeu) et génère un nouveau plateau aléatoire avec les mêmes dimensions. Elle met également à jour le bloc de score:

  • le niveau est incrémenté de 1,
  • le level_score est réinitialisé à 0,
  • le target_score est mis à jour en appliquant le pourcentage scale_score.
Remarques
S'il y avait des gemmes avec pouvoirs (enflammée, étoilée, gravité) ou des hypercubes sur le plateau précédent, ils doivent être préservés dans le nouveau plateau. Par exemple, s'il y avait 2 gemmes enflammées sur le plateau précédent, le nouveau plateau doit également contenir exactement 2 gemmes enflammées (elles peuvent être de types différents et placées à des emplacements différents).
Paramètres
gPointeur vers la structure du jeu.

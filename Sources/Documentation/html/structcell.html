Description détaillée

Structure représentant une case. Utilisée pour communiquer le contenu d'une case à l'interface graphique.

Remarques
Cette structure est utilisée pour transmettre des informations sur une case à l'interface graphique afin qu'elle puisse afficher les visuels appropriés. Cet encodage de l'information de la case est spécifique à l'interface graphique. La façon dont vous choisissez de stocker les informations de la case en interne dans la logique du jeu vous appartient. Vous devrez convertir entre votre représentation interne et cette structure lors de la communication avec l'interface graphique qui se fait par la fonction board_get_cell définie ci-dessous.

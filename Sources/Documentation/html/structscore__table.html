Description détaillée

Structure permettant de stocker le tableau des scores affiché par l'interface graphique (GUI).

Cette structure est utilisée dans trois situations spécifiques :

  • Lors de l'affichage des meilleurs scores dans le menu. Dans ce cas, elle est remplie uniquement avec les scores chargés depuis le fichier de scores.
  • Lors de l'affichage du score à la fin d'un niveau dans une partie classique. Dans ce cas, elle contient les meilleurs scores chargés depuis le fichier de scores ainsi que le score du joueur actuel.
  • Lors de l'affichage du score final à la fin d'une partie classique. Dans ce cas, elle contient les meilleurs scores chargés depuis le fichier de scores ainsi que le score du joueur actuel.
Remarques
Le tableau des noms de joueurs contient des chaînes de caractères d'une longueur maximale de 64 (y compris le caractère nul de fin), ce qui signifie que les noms de joueurs peuvent comporter au maximum 63 caractères.

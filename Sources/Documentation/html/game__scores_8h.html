Description détaillée

Gestion des meilleurs scores en mode classique. Contient les fonctions permettant de charger, sauvegarder et trier les meilleurs scores à partir du fichier de scores.

Il est nécessaire de respecter le format spécifié pour le fichier de scores afin d'assurer un chargement et une sauvegarde corrects des scores (voir la documentation du projet pour plus de détails).

◆ load_score_table()

score_table * load_score_table ( const char * filepath,
int * player_score )

Appelée par l'interface graphique (GUI) pour charger le tableau des scores depuis le fichier de scores.

Cette fonction lit un tableau de scores à partir du fichier spécifié. Si le fichier n'existe pas, elle crée un tableau de scores vide. Si player_score est fourni, il est ajouté comme entrée pour le joueur actuel sous le nom « Player ».

Paramètres
filepathChemin d'accès sur disque au fichier des scores.
player_scorePointeur vers le tableau de score du joueur actuel (NULL si utilisé pour charger les meilleurs scores depuis le menu).

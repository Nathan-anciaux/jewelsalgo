◆ hash_table_insert()

bool hash_table_insert ( hash_table * ht,
int * elements,
ulong i )

Tente d'insérer un élément dans la table de hachage.

Remarques
L'indice i désigne la position de l'élément dans le tableau de stockage externe. Comme chaque élément est encodé comme une séquence d'entiers de taille fixe (champ element_size), la table de hachage lit la séquence de element_size entiers à partir de la position i * element_size dans ce tableau externe.
Renvoie
true si l'élément a été inséré, false s'il était déjà présent. Dans ce dernier cas, la table n'est pas modifiée.
Paramètres
htTable de hachage.
elementsTableau de stockage externe contenant tous les éléments.
iIndice de l'élément à insérer dans le stockage externe.

bool game_implement_solver_move ( game * g,
solver_move * move )

Implémente dans le jeu un coup fourni par le solveur.

Cette fonction prend une structure solver_move représentant un coup unique proposé par le solveur et tente de l'appliquer au jeu. Si le coup est valide dans l'état courant du jeu, il est appliqué et une animation doit être démarrée.

Renvoie
true si le coup a été appliqué avec succès, false sinon.

Description détaillée

Sauvegarde et chargement des états de jeu.

game_save.h

Fonctions utilisées pour sauvegarder et charger des états de jeu. Vous devez respecter le format spécifié pour les fichiers de sauvegarde afin d'assurer la compatibilité (voir la documentation du projet pour les détails).

Documentation du type de l'énumération

◆ save_keywords

enum save_keywords

Mots-clés représentant les différents paramètres pouvant être sauvegardés/chargés dans un fichier d'état de jeu.

Remarques
Rappel : tous les paramètres ne sont pas obligatoires dans un fichier de sauvegarde. Les seuls paramètres obligatoires sont les suivants (les autres peuvent être initialisés à des valeurs par défaut s'ils sont absents) :
  • La largeur et la hauteur du plateau (SK_WIDTH et SK_HEIGHT).
  • L'état du plateau (SK_BOARD).
  • Le mode de jeu (SK_PUZZLE).

Description détaillée

IA pour le mode classique.

Chaque IA implémente une stratégie pour jouer automatiquement. Une fonction d'IA doit jouer un coup dans le jeu et initialiser l'animation correspondante. Si aucun coup n'est possible, elle doit retourner false. En d'autres termes, l'interface graphique (GUI) utilise les fonctions d'IA pour jouer automatiquement en les appelant de manière répétée jusqu'à ce qu'aucun coup ne soit possible.

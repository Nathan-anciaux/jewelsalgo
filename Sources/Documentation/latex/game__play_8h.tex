\doxysubsection{Description détaillée}
Fonctions appelées par l\textquotesingle{}interface (GUI) pour gérer les entrées utilisateur. C\textquotesingle{}est ici que la logique du jeu doit être implémentée. 

Ce fichier déclare les fonctions que l\textquotesingle{}interface appelle pour gérer les interactions utilisateur pendant la partie. Vous devez implémenter ces fonctions pour traiter les clics de souris, les demandes d\textquotesingle{}indice, les détonations, les changements de gravité et les utilisations de la file de stockage. Il vous revient également de gérer les animations \+:
\begin{DoxyItemize}
\item Vous pouvez démarrer des animations avec la fonction "{}game\+\_\+init\+\_\+animation"{} qui est déjà écrite.
\item Une fois une animation démarrée, l\textquotesingle{}interface bloque les entrées utilisateur jusqu\textquotesingle{}à la fin de l\textquotesingle{}animation. À ce moment-\/là, elle appelle la fonction "{}game\+\_\+end\+\_\+animation"{} que vous devez implémenter pour gérer les étapes suivantes.
\end{DoxyItemize}

\begin{DoxyAttention}{Attention}
Vous pouvez écrire des fonctions utilitaires supplémentaires si nécessaire, mais vous ne devez PAS modifier les prototypes de fonctions fournis dans ce fichier. 
\end{DoxyAttention}

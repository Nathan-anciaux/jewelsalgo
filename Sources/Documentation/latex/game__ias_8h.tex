\doxysubsection{Description détaillée}
IA pour le mode classique. 

Chaque IA implémente une stratégie pour jouer automatiquement. Une fonction d\textquotesingle{}IA doit jouer un coup dans le jeu et initialiser l\textquotesingle{}animation correspondante. Si aucun coup n\textquotesingle{}est possible, elle doit retourner false. En d\textquotesingle{}autres termes, l\textquotesingle{}interface graphique (GUI) utilise les fonctions d\textquotesingle{}IA pour jouer automatiquement en les appelant de manière répétée jusqu\textquotesingle{}à ce qu\textquotesingle{}aucun coup ne soit possible.

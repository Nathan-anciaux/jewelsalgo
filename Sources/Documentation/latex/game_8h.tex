Il existe plusieurs types de gemmes avec pouvoirs \+:
\begin{DoxyItemize}
\item Gemmes de gravité \+: lorsqu\textquotesingle{}elles sont échangées avec un autre élément, elles changent la direction de la gravité vers une direction aléatoire (différente de la direction actuelle).

\item Gemmes étoilées \+: lorsqu\textquotesingle{}elles sont cassées, elles effacent toute leur ligne et colonne.
\end{DoxyItemize}

Appelée par l\textquotesingle{}interface pour initialiser un jeu puzzle avec la largeur et la hauteur spécifiées. 

Alloue de la mémoire pour la structure du jeu et initialise le jeu. Les cases sont soit vides, soit remplies aléatoirement avec des types de gemmes. La génération garantit que le jeu est stable \+:
\begin{DoxyItemize}
\item aucune zone destructible n\textquotesingle{}existe, et,
\item il n\textquotesingle{}y a pas de case non vide au-\/dessus d\textquotesingle{}une case vide.
\end{DoxyItemize}

Le paramètre "{}balanced"{} indique si la génération équilibrée est activée. Lorsqu\textquotesingle{}elle est activée, le nombre de chaque type de gemme sur le plateau doit être un multiple de 3.

Le paramètre refill\+\_\+mode spécifie comment la file de stockage doit être initialisée \+:
\begin{DoxyItemize}
\item Si refill\+\_\+mode est 0, la file de stockage est allouée et initialement vide. Les gemmes qui sont éliminées sont stockées dans la file de stockage et peuvent être utilisées pour remplir le plateau plus tard.
\item Si refill\+\_\+mode est 1, la file de stockage est allouée et doit être remplie avec une séquence aléatoire de rochers et de bombes. La longueur de la séquence est fournie par le paramètre ini. Ce paramètre ne doit pas dépasser le nombre total de cases sur le plateau (s\textquotesingle{}il le fait, il doit être défini à width \texorpdfstring{$\ast$}{*} height).
\item Si refill\+\_\+mode est 2, la file de stockage n\textquotesingle{}est pas utilisée et ne doit pas être allouée.
\end{DoxyItemize}

Appelée par l\textquotesingle{}interface lorsqu\textquotesingle{}un niveau se termine en mode classique pour générer un nouveau plateau de jeu. 

Cette fonction libère le plateau de jeu actuel (mais pas toute la structure du jeu) et génère un nouveau plateau aléatoire avec les mêmes dimensions. Elle met également à jour le bloc de score\+:
\begin{DoxyItemize}
\item le niveau est incrémenté de 1,
\item le level\+\_\+score est réinitialisé à 0,
\item le target\+\_\+score est mis à jour en appliquant le pourcentage scale\+\_\+score.
\end{DoxyItemize}

\begin{DoxyRemark}{Remarques}
S\textquotesingle{}il y avait des gemmes avec pouvoirs (enflammée, étoilée, gravité) ou des hypercubes sur le plateau précédent, ils doivent être préservés dans le nouveau plateau. Par exemple, s\textquotesingle{}il y avait 2 gemmes enflammées sur le plateau précédent, le nouveau plateau doit également contenir exactement 2 gemmes enflammées (elles peuvent être de types différents et placées à des emplacements différents). 
\end{DoxyRemark}

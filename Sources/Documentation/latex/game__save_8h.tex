Sauvegarde et chargement des états de jeu. 

\doxylink{game__save_8h}{game\+\_\+save.\+h}

Fonctions utilisées pour sauvegarder et charger des états de jeu. Vous devez respecter le format spécifié pour les fichiers de sauvegarde afin d\textquotesingle{}assurer la compatibilité (voir la documentation du projet pour les détails).

Mots-\/clés représentant les différents paramètres pouvant être sauvegardés/chargés dans un fichier d\textquotesingle{}état de jeu. 

\begin{DoxyRemark}{Remarques}
Rappel \+: tous les paramètres ne sont pas obligatoires dans un fichier de sauvegarde. Les seuls paramètres obligatoires sont les suivants (les autres peuvent être initialisés à des valeurs par défaut s\textquotesingle{}ils sont absents) \+:
\begin{DoxyItemize}
\item La largeur et la hauteur du plateau (SK\+\_\+\+WIDTH et SK\+\_\+\+HEIGHT).
\item L\textquotesingle{}état du plateau (SK\+\_\+\+BOARD).
\item Le mode de jeu (SK\+\_\+\+PUZZLE). 
\end{DoxyItemize}
\end{DoxyRemark}

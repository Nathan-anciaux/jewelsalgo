\doxysubsection{Description détaillée}
Structure représentant un plateau de jeu. 

Cette structure est utilisée pour représenter un plateau de jeu. L\textquotesingle{}implémentation réelle du plateau vous appartient, mais elle doit au moins contenir les informations suivantes \+:
\begin{DoxyItemize}
\item la largeur et la hauteur du plateau,
\item la direction de la gravité,
\item la case actuellement sélectionnée par le joueur (ou un indicateur indiquant qu\textquotesingle{}aucune case n\textquotesingle{}est sélectionnée),
\item le contenu de chaque case, et
\item la file de stockage si elle est utilisée (uniquement en mode puzzle dans un mode nécessitant une file de stockage).
\end{DoxyItemize}

Vous pouvez ajouter des champs supplémentaires si nécessaire pour votre implémentation (cela sera utile pour stocker des informations lorsqu\textquotesingle{}une animation est en cours, par exemple).

\begin{DoxyRemark}{Remarques}
Étant donné que l\textquotesingle{}implémentation du plateau vous appartient, l\textquotesingle{}interface graphique ne sait pas comment l\textquotesingle{}interpréter directement. C\textquotesingle{}est pourquoi vous devez écrire des fonctions que l\textquotesingle{}interface graphique appellera pour récupérer les informations du plateau. 
\end{DoxyRemark}

\doxysubsection{Description détaillée}
Gestion des meilleurs scores en mode classique. Contient les fonctions permettant de charger, sauvegarder et trier les meilleurs scores à partir du fichier de scores. 

Il est nécessaire de respecter le format spécifié pour le fichier de scores afin d\textquotesingle{}assurer un chargement et une sauvegarde corrects des scores (voir la documentation du projet pour plus de détails).

Appelée par l\textquotesingle{}interface graphique (GUI) pour charger le tableau des scores depuis le fichier de scores. 

Cette fonction lit un tableau de scores à partir du fichier spécifié. Si le fichier n\textquotesingle{}existe pas, elle crée un tableau de scores vide. Si player\+\_\+score est fourni, il est ajouté comme entrée pour le joueur actuel sous le nom « Player ».

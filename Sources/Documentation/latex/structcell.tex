\doxysubsection{Description détaillée}
Structure représentant une case. Utilisée pour communiquer le contenu d\textquotesingle{}une case à l\textquotesingle{}interface graphique. 

\begin{DoxyRemark}{Remarques}
Cette structure est utilisée pour transmettre des informations sur une case à l\textquotesingle{}interface graphique afin qu\textquotesingle{}elle puisse afficher les visuels appropriés. Cet encodage de l\textquotesingle{}information de la case est spécifique à l\textquotesingle{}interface graphique. La façon dont vous choisissez de stocker les informations de la case en interne dans la logique du jeu vous appartient. Vous devrez convertir entre votre représentation interne et cette structure lors de la communication avec l\textquotesingle{}interface graphique qui se fait par la fonction board\+\_\+get\+\_\+cell définie ci-\/dessous. 
\end{DoxyRemark}

\doxysubsection{Description détaillée}
Structure permettant de stocker le tableau des scores affiché par l\textquotesingle{}interface graphique (GUI). 

Cette structure est utilisée dans trois situations spécifiques \+:
\begin{DoxyItemize}
\item Lors de l\textquotesingle{}affichage des meilleurs scores dans le menu. Dans ce cas, elle est remplie uniquement avec les scores chargés depuis le fichier de scores.
\item Lors de l\textquotesingle{}affichage du score à la fin d\textquotesingle{}un niveau dans une partie classique. Dans ce cas, elle contient les meilleurs scores chargés depuis le fichier de scores ainsi que le score du joueur actuel.
\item Lors de l\textquotesingle{}affichage du score final à la fin d\textquotesingle{}une partie classique. Dans ce cas, elle contient les meilleurs scores chargés depuis le fichier de scores ainsi que le score du joueur actuel.
\end{DoxyItemize}

\begin{DoxyRemark}{Remarques}
Le tableau des noms de joueurs contient des chaînes de caractères d\textquotesingle{}une longueur maximale de 64 (y compris le caractère nul de fin), ce qui signifie que les noms de joueurs peuvent comporter au maximum 63 caractères. 
\end{DoxyRemark}

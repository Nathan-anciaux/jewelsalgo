\doxysubsection{Description détaillée}
Structure représentant un jeu complet. 

Cette structure contient toutes les informations sur un jeu en cours. Elle inclut le plateau de jeu, les paramètres du jeu (mode, options) et le score.

\begin{DoxyRemark}{Remarques}
Le paramètre le plus important est le booléen "{}puzzle"{} qui indique si le jeu est en mode puzzle (true) ou en mode classique (false). En fonction de ce paramètre, certains autres champs peuvent ne pas être pertinents et doivent être définis à des valeurs spécifiques.

Les paramètres communs aux deux modes sont \+:
\begin{DoxyItemize}
\item lines \+: si le jeu utilise des zones destructibles basées sur les lignes ou les composantes fortement connexes (SCC),
\item upgrades \+: si le jeu peut améliorer les gemmes (en gemmes enflammées, gemmes étoilées et hypercubes),
\item gravity\+\_\+control \+: comment le joueur peut contrôler la gravité (0 \+: ne peut pas changer, 1 \+: rotation horaire, 2 \+: libre).
\end{DoxyItemize}

Les paramètres spécifiques au mode classique sont (nodelay doit toujours être à true en mode puzzle) \+:
\begin{DoxyItemize}
\item nodelay \+: si le jeu est en mode nodelay. true \+: les gemmes sont immédiatement détruites (toujours à cette valeur en mode puzzle), false \+: destruction sur demande,
\item easy \+: si le jeu est en mode facile (de nouvelles gemmes sont générées de sorte qu\textquotesingle{}une solution existe toujours),
\item gravity\+\_\+gems \+: si le jeu peut générer des gemmes de gravité,
\item bombs \+: si le jeu peut générer des bombes.
\end{DoxyItemize}

L\textquotesingle{}unique paramètre spécifique au mode puzzle spécifie comment la file de stockage est utilisée (il doit être défini à "{}pas de file"{} (valeur 2) en mode classique) \+:
\begin{DoxyItemize}
\item refill\+\_\+mode \+: le mode de stockage utilisé en mode puzzle (0 \+: stocke les gemmes éliminées, 1 \+: file prédéterminée de rochers et bombes, 2 \+: Pas de file de stockage). 
\end{DoxyItemize}
\end{DoxyRemark}
